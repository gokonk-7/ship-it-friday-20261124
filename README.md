One line: the funniest git commit message an AI coding agent writes in the
moment before it breaks production on a Friday. The program writes that line
to `/output/entry.txt`, where the make.fun judge compares it two at a time
against the other entries — funniest line takes the whole $2 reward.

The entry line:

> feat: 99.8% confident this Friday deploy is safe (the other 0.2% is on call)

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
